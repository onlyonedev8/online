DailyPulse AI discovery files

Files included:
- robots.txt: crawler access instructions
- sitemap.xml: lists the known public homepage
- llms.txt: optional plain-language guide for AI systems

INSTALLATION
1. Open the GitHub repository that publishes https://onlyonedev8.github.io/online/
2. Upload all three files into the same published root directory as the site's index.html.
3. Commit the changes and wait for GitHub Pages to publish.
4. Test these addresses:
   https://onlyonedev8.github.io/online/robots.txt
   https://onlyonedev8.github.io/online/sitemap.xml
   https://onlyonedev8.github.io/online/llms.txt

IMPORTANT
These files help compatible crawlers understand and discover the site; they do not force AI agents to visit it or guarantee that search engines will index it. The sitemap lists only the homepage because the known DailyPulse setup uses category/feed loading and no confirmed individual article-page URLs were available. If the site later adds distinct article pages, add their canonical URLs to the sitemap.
